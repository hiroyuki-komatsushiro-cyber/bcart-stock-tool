# Bカート在庫更新ツール

BrewtopeHub の在庫データと Bカートの商品データを突き合わせて、
Bカートの在庫インポート用CSVを作る道具です。

- 使い方: 公開URLを開き、2つのファイルを選んで「在庫を計算する」を押すだけ
- **ブラウザの中だけで動きます。** ファイルの内容はどこにも送信・保存されません
  （サーバーを使っていないため、社外から開いても業務データが外に出ません）
- 設定（掛け率・定番品の品番）は、使う人のブラウザにだけ保存されます

## やっていること

1. BrewtopeHub の在庫から、指定した保管場所の行だけを使う（入数が空の行は除く）
2. フリー在庫 = 在庫数 − 取り置き在庫（取り置き列が無ければ在庫数そのまま）
3. 同じ商品コードの行を合算する
4. 「定番品」に登録した品番は掛け率（既定70%）を掛け、それ以外はそのまま。どちらも切り捨て
5. 商品コードを Bカートの在庫実体の品番に変換する
6. 画面で確認・手修正してから、CSVをダウンロードするか表をコピーする

## 列の対応づけ

ファイルの見出しから自動で推測します。違っていれば画面で選び直せます。
選んだ内容はブラウザに記憶されるので、次回からは選び直す必要はありません。

## 更新のしかた

このフォルダで `index.html` を編集してコミット・pushすると、
数十秒で GitHub Pages に反映されます。
